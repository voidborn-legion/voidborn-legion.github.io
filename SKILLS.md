# Skills für die Academy

Installiert am 23.10.2026 in den lokalen Skills-Ordner. Die Skills sind Werkzeuge für die Bearbeitung; die öffentliche Website lädt sie nicht.

| Skill | Quelle | Einsatz |
| --- | --- | --- |
| Humanizer | https://github.com/blader/humanizer | Konkrete deutsche Texte, Aussagen und Quellen erhalten |
| UX Writing | https://github.com/content-designer/ux-writing-skill | Beschriftungen, Suche, fehlende Treffer, Vorschauhinweise |
| Taste | https://github.com/Leonxlnx/taste-skill | Kürzere Titel, redaktionelle Anordnung und unterschiedliche Abschnittsformen |
| UI UX Pro Max | https://github.com/nextlevelbuilder/ui-ux-pro-max-skill | Suche, Informationshierarchie, Vue-Semantik und mobile Bedienung |
| Web Design Guidelines | https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines | Fokus, native Bedienelemente, Bildgrößen und URL-Zustand |

Impeccable bleibt für die abschließende Designprüfung im Einsatz.

## Abwägungen
Die vorhandene Fantasy-Gestaltung, VitePress und Vue bleiben erhalten. Ein Wiki benötigt ruhige Leseseiten; Vorgaben für viele Animationen, vier dekorative Bilder oder große Scrollinszenierungen passen hier nicht. Taste wird deshalb für Anordnung und Textqualität eingesetzt. Sein Quellen-Lint wurde verwendet; Browserprüfungen erfolgen mit dem vorhandenen Browserwerkzeug statt seinem eigenen Browser-Inspector.

UI UX Pro Max empfahl für „gaming“ zunächst einen Neon-/3D-Look. Die Empfehlung für „knowledge base documentation“ lieferte die passendere Such- und Navigationsstruktur. Palette und Schriften folgen weiter dem bestätigten Voidborn-Design. Keine zusätzlichen Bibliotheken oder externen Dienste wurden dafür eingebunden.

## Inhalt
Sprachregeln stehen in VOICE.md. Die Spielguide-Migration ist weiterhin eine spätere Phase. Die neue Beispielseite erklärt die Academy, ohne ungeprüfte Spielwerte zu erfinden.
